# Inspection audio

`8-seconds.mp3` and `12-seconds.mp3` are the inspection cues from
[cube-tui](https://github.com/enekocm7/cube-tui) (`assets/audio`), which is
MIT-licensed. They are embedded into the `cube-ui` crate and played during WCA
inspection when the "Inspection audio cues" setting is on.

# Personal best chime

`personal-best.mp3` was synthesized for this project, so it carries the
project's own license. It plays for a new personal best when the "Personal best
sound" setting is on.
